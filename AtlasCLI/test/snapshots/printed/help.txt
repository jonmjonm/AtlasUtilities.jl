$ mapatlas --help


  mapatlas v0.1.0



Usage

  mapatlas <command>

Commands

  add                                                       Add CycleWalk pushable writer function(s) (e.g.
                                                            get_log_spanning_trees) to every map in atlas
                                                            Atlas1, writing the augmented atlas to Atlas2; the dual
                                                            graph is supplied via --config and/or the column
                                                            flags.

  convert                                                   Convert atlas src to Atlas format version --
                                                            to (1 or 2), writing dst.
                                                            ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
                                                            Only the formatVersion in the header and the
                                                            district assignment of each map are rewritten; the banner,
                                                            the atlas parameters and the name, weight and data of every
                                                            map are copied byte for byte. Converting back gives the same
                                                            districting for every map. A districting that format v2
                                                            cannot hold (a region both whole and split) stops the
                                                            conversion with an error naming the line and map. The two
                                                            versions are described in atlas_format.md of
                                                            AtlasIO.

  extract-assignments                                       Write atlas Atlas1 per-map district assignments to a single
                                                            wide CSV, named from the Atlas1 basename plus -
                                                            assignments.csv (or .csv.gz): one row per
                                                            map, columns name (the map name) then one column
                                                            per unit holding the district number of that unit in the
                                                            map. For a single-level atlas the units are its nodes. For a
                                                            multiscale atlas (whose maps mix whole counties and split
                                                            ones) the district of each unit is that of the region
                                                            covering it in each map; the units are the finest units of
                                                            the dual graph with --graph, otherwise the finest
                                                            regions seen in the atlas.

  extract-map-data                                          Write each map-data field of atlas Atlas1 to its own CSV
                                                            (one row per map: the map name, the field value, then the
                                                            map weight in a last map_weight column) in a
                                                            directory named after the atlas, plus an about.md
                                                            describing the atlas (its mapatlas info header,
                                                            minus the embedded script, with the source atlas name and
                                                            extraction date); --add also computes CycleWalk
                                                            writer functions to extract, using the same graph inputs as
                                                            mapatlas add.

  extract-map-data-histogram                                Like extract-map-data, but instead of writing per-
                                                            map CSV rows, accumulate the values of each map-data field
                                                            into a StreamHistogram: a single histogram for a scalar
                                                            field, or one histogram per index for a vector field (with
                                                            --no-sort, index j gets raw entry
                                                            j; by default entry j of each map vector
                                                            is sorted ascending first, so histogram j holds
                                                            the j-th order statistic across maps rather than
                                                            raw index j). The first --burn-in maps
                                                            are skipped entirely. Writes a CSV + JSON pair per field,
                                                            named <field>-histogram.csv and <field>-
                                                            histogram.json (or
                                                            .csv.gz/.json.gz), plus
                                                            about.md, to the same directory extract-map-
                                                            data uses. Each value is counted both once and with its
                                                            map weight. The CSV holds only the exact per-bin edges,
                                                            counts (exact_count) and sums of map weights
                                                            (weight_sum), a plain numeric table for loading
                                                            straight into a histogram plot; the JSON holds everything
                                                            else – per-index summary statistics, unweighted and weighted
                                                            (total_weight, effective_sample_size,
                                                            weighted_mean, ...), moment errors, the ASH-
                                                            density bin counts and weights, and the bin edges again – as
                                                            a human-readable dictionary keyed by index.

  info                                                      Print the header of an Atlas file (metadata and atlas
                                                            parameters); the bulky embedded generating script,
                                                            its script_includes, and the TOML config are never
                                                            printed, though their presence is noted (use --extract-
                                                            script to write them out).

  list-map-data                                             List the names of the data fields (e.g.
                                                            log_spanning_trees) contained in atlas Atlas1
                                                            first map, one per line, sorted.

  list-nodes                                                List the node ids in atlas Atlas1 k-th map (1-based, k=1 by
                                                            default), as a JSON array of strings.

  relabel                                                   Relabel district numbers across atlas Atlas1 so consecutive
                                                            maps stay as similar as possible, writing the result to
                                                            Atlas2.

  summarize-map-data                                        Print, for every map-data field of atlas Atlas1, its mean,
                                                            standard deviation, and [min, 25% quartile, median, 75%
                                                            quartile, max], each computed from a StreamHistogram built
                                                            over the field values (one histogram per index for a vector
                                                            field, each map vector sorted ascending first, so histogram
                                                            j holds the j-th order statistic across maps). When the map
                                                            weights vary, the weighted mean, standard deviation and
                                                            quartiles (each map counting its weight) follow, with the
                                                            effective sample size. Warns when too much of a field data
                                                            set fell outside its histogram learned range (the tail
                                                            quantile estimates lean on a single coarse interpolation
                                                            across that whole bucket), or when a quartile estimate
                                                            disagrees with the ASH density estimate for that field by
                                                            more than a couple of percentage points (the within-bin-
                                                            uniform interpolation may not fit the shape of that field).



Flags

  -h, --help                                                Print this help message.
  --version                                                 Print version.
[exit 0]
